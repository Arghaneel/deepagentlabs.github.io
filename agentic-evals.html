60-second quickstart

Three lines to your first eval

The fastest way to write an eval — just data, a task, and scorers.

capitals_eval.py
from agentic_evals import Eval, equals

Eval(
    "capitals",
    data=[
        {"input": "France", "expected": "Paris"},
        {"input": "Japan", "expected": "Tokyo"},
    ],
    task=lambda x: my_agent(x["input"]),
    scores=[equals],
)
$ python capitals_eval.py

For complex expectations: trace-aware assertions, tool calls, latency, cost.

support_suite.py
from agentic_evals import (
    EvalTrace, EvalSpan, EvaluationSample, TestCase, TestSuite,
    evaluate_suite
)

suite = TestSuite(
    name="support-answers",
    version="1",
    cases=[
        TestCase(
            id="refund-1",
            name="Answer contains total",
            expected_contains=["42"],
            required_tools=["calculator"],
            max_latency_ms=2000,
        )
    ],
)

sample = EvaluationSample(
    case_id="refund-1",
    output="The total is 42.",
    trace=EvalTrace(
        trace_id="trace-1",
        total_latency_ms=350,
        spans=[EvalSpan(tool_name="calculator")],
    ),
)

report = evaluate_suite(suite, [sample])
print(f"Pass rate: {report.summary.pass_rate}")  # 1.0

Bring your own LLM judge or business logic.

custom_eval.py
from agentic_evals import (
    LLMJudgeEvaluator, EvaluationContext, Score, EvaluatorRegistry
)

def my_judge(context: EvaluationContext) -> Score:
    # Your LLM call here
    correct = expected_fact in context.sample.output
    return Score(
        name="factuality",
        value=1.0 if correct else 0.0,
        passed=correct,
        explanation="Fact verified" if correct else "Hallucinated"
    )

registry = EvaluatorRegistry()
registry.register(LLMJudgeEvaluator("fact_check", my_judge))

# Use in your suite
report = evaluate_suite(suite, samples, registry=registry)
Built for production

Everything you need to evaluate AI systems

✓

Deterministic Checks

Exact match, substring, JSON Schema, regex, field presence, required tool calls, and custom business rules — no LLM needed.

🤖

LLM-as-Judge

Provider-neutral rubric scoring. 10 built-in templates: factuality, translation, security, SQL correctness, PII leakage, and more.

🎯

Trace-Aware Scoring

Evaluate tool usage, call precision/recall, latency, cost, and turn counts alongside output correctness.

🚪

Release Gates

CI-ready pass/fail gates on pass rate, cost, latency, and custom thresholds. Exit 0 if everything passes, 1 if not.

🔌

Live Targets

Point suites at real running systems (trusted Python callables or HTTP endpoints) instead of pre-recorded samples.

📦

Eval Packs

Shareable YAML/JSON bundles pairing a TestSuite with the scorers it needs. 3 built-in packs ship with the package.

Pre-built Scorers

Ready-made evaluation functions

Text Scorers (Deterministic)

  • exact_match, contains_all, contains_any
  • levenshtein_similarity, embedding_similarity (provider-neutral)
  • valid_json, json_diff, numeric_diff
  • regex_match, starts_with, ends_with, numeric_range

Rubric Scorers (LLM-Graded)

  • FACTUALITY — Checks if output matches facts
  • CLOSED_QA — Evaluates QA correctness
  • SUMMARY_QUALITY — Rates summary quality
  • BATTLE — Pairwise A/B comparison
  • MODERATION, TRANSLATION, SECURITY, SQL_CORRECTNESS, PII_LEAKAGE, POSSIBLE

Trajectory Scorers (Trace-Aware)

  • tool_call_precision — Correct tools selected
  • tool_call_recall — All needed tools called
  • no_redundant_tool_calls — No duplicate work
  • trajectory_efficiency — Optimal path taken
Real-world examples

How to evaluate different systems

Fact-Checking QA Agent

from agentic_evals import TestSuite, TestCase, evaluate_suite, default_registry

suite = TestSuite(
    name="factual_qa",
    version="1",
    cases=[
        TestCase(
            id="shakespeare",
            name="Romeo and Juliet author",
            expected_output="William Shakespeare",
            evaluators=[EvaluatorConfig(name="levenshtein_similarity", threshold=0.9)],
        ),
        TestCase(
            id="titanic",
            name="Titanic sinking year",
            expected_contains=["1912"],
            max_latency_ms=500,
        ),
    ]
)

report = evaluate_suite(suite, samples, registry=default_registry())
print(f"Factual accuracy: {report.summary.pass_rate * 100:.1f}%")

Customer Support Agent

from agentic_evals import TestSuite, TestCase, EvaluatorConfig

suite = TestSuite(
    name="support",
    version="1",
    cases=[
        TestCase(
            id="order-lookup",
            name="Find order status",
            required_tools=["get_order"],

            max_cost_usd=0.05,
        ),
        TestCase(
            id="refund-process",

            required_tools=["lookup_refund", "process_payment"],
            expected_contains=["confirmed", "24 hours"],
        ),
    ]
)

report = evaluate_suite(suite, samples)
print(f"Support quality: {report.summary.pass_rate * 100:.1f}%")

Release Gate in CI

from agentic_evals import evaluate_suite, evaluate_gate, GateConfig

# Run your evals
report = evaluate_suite(suite, samples, registry=registry)

# CI gate on pass rate, cost, latency
decision = evaluate_gate(
    report,
    GateConfig(
        min_pass_rate=0.95,
        max_average_latency_ms=1500,
        max_total_cost_usd=0.25
    )
)

if not decision.passed:
    raise SystemExit(f"Release gate failed: {decision.reasons}")

# Exit 0 if gate passes, 1 if it fails

Why agentic-evals

When to use it

✓ Use agentic-evals if...

  • You need to score LLM/agent outputs programmatically
  • You want deterministic checks and LLM-as-judge
  • You need to evaluate tool usage, not just output text
  • You want a CI gate for agent quality
  • You work with multiple agent frameworks
  • You need custom evaluation logic

🔄 Use AgenticLens if...

  • You need live dashboards and visualizations
  • You want dataset versioning and splitting
  • You need judge calibration tools
  • You want HTML evaluation reports
  • You need production monitoring at scale

Note: agentic-evals and AgenticLens work together. AgenticLens can ingest agentic-evals traces, and you can use agentic-evals standalone without AgenticLens.
