SUPERVISION TRAVELS WITH THE AGENT

Guardrails around the action. Intent throughout the loop.

Each new proposal returns through the same checks. Context is restored before the agent moves on, critique keeps the action aligned with its goal, and the execution gate stays held until automated checks pass and any required human review is complete.
